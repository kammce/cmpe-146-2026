How it works
The counter is held at 0 while the input pin is LOW. The instant the pin goes HIGH (rising edge), the counter is zeroed and starts counting on every clock tick after that. The instant the pin goes LOW again (falling edge), the current count is latched into the Capture Register. Because the rising-edge tick itself reads 0, the captured value is one tick less than the configured pulse width -- a classic edge-counting gotcha worth watching for on real hardware.
